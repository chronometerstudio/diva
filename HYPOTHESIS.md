# Гипотеза хрупкости: исследовательская программа

Автор идеи: Я. Деев (Chronometer Studio). Редакция: 21.10.2026.
Статус: рабочая гипотеза с планом проверки. Не является доказательством P ≠ NP и не претендует на него (см. §4).

## 1. Исходная интуиция

1. NP-полных задач бесконечно много; список Карпа (21 задача, 1972) — начало перечисления, а не его конец. Изменение параметра задачи (число цветов, арность дизъюнкта, плотность распределения чисел) даёт новую задачу, иногда — по другую сторону границы P/NP (2-раскраска → 3-раскраска, 2-SAT → 3-SAT).
2. У каждой задачи есть свои «ключи» — сильные эвристики, дающие большое ускорение именно на ней. Ключи переносятся на другие задачи, но их вклад там исчезающе мал: измеримы только сильнейшие (условно 50 %, 30 %, 10 %…), хвост ряда не виден.
3. Ряд вкладов сходится: никакая сумма эвристик не даёт 100 %. Иначе говоря, набор локальных ключей не убирает экспоненту, а лишь меняет константу перед ней.
4. Хрупкость: метод, сильный на «родительской» задаче, при минимальной мутации входа («сестра») теряет силу скачком; доработка под сестру ослабляет его на родителе.
5. Числовые задачи (Subset Sum, Partition, целочисленное программирование) дают *непрерывную* цепочку сестёр: плотность распределения чисел меняется на бит — получается новая задача. На такой цепочке срыв эвристики можно измерять как функцию параметра.

## 2. Что уже установлено (экспериментально, Diva, 19–20.10.2026)

- Закон цены опровержения для случайной 3-раскраски у порога (162 графа, n = 150…500; предрегистрация на 600–700):
  log₂ C = 1.16 + n·(0.120 − 0.0204·ρ − 0.0527·t), ρ — плотность зерна (самый плотный подграф на 12–32 % вершин), t — треугольники внутри зерна. Остаток ≈ 1 бит.
- Разделение шкал в данных: все методы движка (память лемм, перезапуски, BVE, наследование лемм, приоры) меняли только множитель (от ±3 % до ×1.6); показатель экспоненты менялся только со структурой входа (ρ, t, регулярность).
- Наблюдения хрупкости: закон зерна не работает на регулярных графах (зерна нет); Kissat без закрепления клики в 4–6 раз медленнее, чем с ним; наследование лемм разогрева даёт −15 % на одном графе и +5 % на другом; табу-поиск не находит решений на n = 700, хотя находит на 500.
- Разрез на кубы аддитивен тогда и только тогда, когда хаб лежит внутри минимального нераскрашиваемого подграфа (1.0 против 1.7–1.9).

Эти факты согласуются с §1, но описывают один домен и один класс алгоритмов.

## 3. Три проверяемых утверждения

**H-A. Инвариант затухания.** Для семейства сестёр с контролируемой мутацией относительная потеря эффективности фиксированного метода описывается одной кривой в разных доменах (графы, формулы, числа). Фальсифицируется, если кривые различны.

**H-B. Разделение шкал.** Мутации делятся на два типа: сдвигающие показатель экспоненты (смена класса входов: плотность, регулярность, порог) и сдвигающие множитель (всё, на чём живут эвристики). Хрупкость — свойство множителя; показатель — инвариант класса входов. Фальсифицируется, если найдётся эвристика, меняющая показатель на фиксированном классе.

**H-C. Теорема для фиксированной системы доказательств.** Для резолюции (и, как следствие, CDCL) на семействе сестёр никакое добавление полиномиального числа «лемм-ключей» не меняет показатель экспоненты. Это утверждение о системе доказательств, а не о всех алгоритмах; у него есть известная техника (ширина резолюции, Бен-Сассон–Вигдерсон, 2001), а наши измерения показателя подсказывают, какую константу доказывать.

## 4. Почему это не доказательство P ≠ NP — и границы программы

- **Шкала.** Хрупкость эвристик — потеря множителя; P ≠ NP — утверждение о показателе. Срыв ключа с 50 % до 0 % делает полиномиальный алгоритм вдвое медленнее, а не экспоненциальным.
- **Квантор.** «Все известные методы хрупки» не переносится на все возможные полиномиальные алгоритмы; экспериментом это не закрывается. Полиномиальность не обязана быть устойчивой к мутациям (2-SAT → 3-SAT — мутация через границу класса).
- **Барьер.** Рассуждение, использующее только поведение входов и не опирающееся на устройство вычислителя, релятивизируется и по Бейкеру–Гиллу–Соловэю (1975) не может доказать P ≠ NP.

Поэтому цель программы — эмпирические законы H-A, H-B и теорема H-C, а не P ≠ NP.

## 5. План проверки

1. **Семейство сестёр для 3-раскраски** (есть инструменты): случайный граф у порога → регулярный той же плотности → граф с плантированной раскраской → решётка с добавленными случайными рёбрами (доля шума как параметр). Метод фиксирован (Diva, опции gvwuGB). Измерять раздельно: показатель s в 2^(n·s) по нескольким n и множитель.
2. **Subset Sum по плотности** (готовые методы: LLL, динамика, ветвление): плотность от 0.5 до 1.2 с шагом; известный переход около 0.94 — опорная точка для калибровки.
3. **Случайный 3-SAT по плотности** (порог 4.27): тот же протокол.
4. Для каждого семейства — предрегистрация предсказаний до прогонов, как делалось для закона опровержения.
5. Сравнение кривых затухания между доменами (H-A), классификация мутаций по шкалам (H-B).
